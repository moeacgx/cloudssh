## 本次版本主要更新

### ✨ 新增功能 · MCP 账号归属

- **查密钥：** 在「MCP 管理 → 调用密钥」中，实例管理员可以分组查看自己和其他账号的密钥，核对权限、状态和到期时间。普通用户仍只能看到自己的密钥。
- **查调用：** 在「调用记录」中，实例管理员可以看到每次调用使用的密钥属于哪个账号。同名密钥不必再靠名称区分；无法识别归属时显示「未知账号」。

### 🐛 修复问题 · 升级后页面加载失败

- 修复前端脚本或样式文件短暂缺失时，Nginx 给 404 响应也加上一年缓存期限的问题。成功返回的静态资源仍可长期缓存。

### ✅ 验证范围

- 37 项 MCP 管理接口、面板和 Nginx 回归测试通过；[正式发布流程](https://github.com/moeacgx/cloudssh/actions/runs/44259687436)完成测试、构建和 14 个发布附件的校验。
- 发布前未在生产实例完成账号归属验收。升级后可用实例管理员账号打开「调用记录」，核对一条已知 MCP 调用的所属账号。

## 🚀 部署与更新

### 🔄 面板内一键更新

使用 `auto` 或 `binary` 模式：进入 **管理 → 版本**，选择 `2.6.0-cloudssh.61` 更新。面板会自动匹配服务器架构，无需手动下载附件。

### 🐳 宿主机镜像更新

使用 `image` 模式：在部署目录运行项目的[镜像更新脚本](https://github.com/moeacgx/cloudssh/blob/release-2.6.0-cloudssh.61-tag/docs/CLOUDSSH-UPDATES.md#生产快速重启更新)，固定升级到本版：

```sh
sh scripts/cloudssh-host-image-update.sh 2.6.0-cloudssh.61
```

> [!NOTE]
> 如果升级后个别页面仍加载失败，请检查对应 JS 或 CSS 请求。新版本不会自动清除 CDN 已缓存的旧 404；若源站已返回 200 而 CDN 仍返回 404，只需刷新该资源的 CDN 缓存。
