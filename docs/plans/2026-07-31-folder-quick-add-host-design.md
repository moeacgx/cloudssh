# 文件夹快捷新增主机设计

## 目标

在主机树的每个文件夹行右侧、文件夹管理按钮之前增加 `+` 图标。点击后直接打开现有
“新增主机”窗口，并自动预填当前项目和当前文件夹；保存成功后主机立即显示在该文件夹。

## 交互

- `+` 只在当前用户可管理该项目文件夹时显示，含义通过 Tooltip 和无障碍标签说明。
- 点击阻止文件夹折叠事件与拖拽事件传播，不改变当前文件夹展开状态。
- 复用现有 `HostManager`/`HostEditor`，不新增第二套主机表单。
- 打开表单时传入不可混淆的 `projectId` 与规范化 `folderPath`；项目保持当前值，文件夹默认
  当前行，但用户仍可在允许范围内调整表单其他字段。
- 保存成功后刷新当前项目主机树、自动展开目标文件夹，并清除一次性预填状态；取消窗口
  不产生任何数据修改。

## 数据一致性

- 创建请求必须以当前项目 ID 为准，不回退到个人空间。
- 后端验证文件夹属于该项目且调用者有管理权限，不能接受前端伪造的跨项目文件夹路径。
- 若保存期间文件夹被删除，创建失败并提示用户重新选择文件夹，不静默放入根目录。
- 项目文件夹使用项目级元数据，不写入全局共享文件夹配置。

## 测试

- 组件测试覆盖按钮位置、权限隐藏、事件阻止、项目和文件夹预填、取消与保存刷新。
- API/仓库测试覆盖跨项目伪造、已删除文件夹和无管理权限。
- 端到端验证在个人项目和团队项目中新增后均立即出现在正确文件夹。
