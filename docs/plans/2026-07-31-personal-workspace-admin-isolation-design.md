# 个人空间管理员隔离设计

## 目标

项目切换器始终只显示当前用户自己的个人空间及其有权访问的团队项目。即使是实例管理员，
也不能在日常工作台看到其他用户的个人空间。实例管理员只能从“用户管理”显式进入目标
用户的个人空间，并可连接、编辑和删除其中的主机；全部操作进入审计。

## 接口隔离

- 普通项目列表接口永远过滤其他用户的 `personal` 项目，实例管理员不例外。
- 普通项目详情、文件夹、主机和连接接口访问其他用户个人空间时统一返回 404，避免暴露
  资源是否存在。
- 新增独立的管理员个人空间接口，路径归属 `/admin/users/:userId/personal-project`，只接受
  实例管理员会话，不复用普通项目的“管理员可见全部”分支。
- 管理员接口显式提供个人空间摘要、文件夹树、主机详情、连接、编辑和删除能力，并对每次
  访问记录操作者、目标用户、项目、主机、动作和结果。

## 用户界面

- 项目切换器删除实例管理员查看其他个人空间的特殊逻辑。
- “用户管理”中的用户行增加“个人空间”入口，仅实例管理员可见。
- 个人空间管理页明确显示目标用户名和管理员访问提示，复用现有项目文件夹树与主机编辑、
  连接能力，但所有请求走管理员专用接口。
- 退出页面后返回管理员自己的当前项目，不把代管个人空间写入常规项目选择偏好。

## 删除语义

- 若主机同时关联其他项目，“删除”只解除它与目标个人空间的关联。
- 若主机没有其他项目关联，才删除主机记录及只属于它的凭据镜像。
- 删除前界面明确显示“解除关联”或“永久删除”，后端在事务内再次检查关联数量，避免
  并发变化造成误删。

## 权限与审计

- 只有实例管理员可以调用专用接口；团队管理员和项目管理员无权查看任何其他个人空间。
- 管理员连接沿用目标主机的服务端凭据，但凭据不可查看、复制或导出。
- 管理员编辑不能改变个人空间所有者，也不能把个人空间变成团队项目。
- 管理员访问、连接、编辑、解除关联和永久删除均写入审计；错误响应不包含凭据和内部
  加密字段。

## 测试

- 覆盖普通用户、团队管理员、项目管理员和实例管理员的项目列表与 404 行为。
- 覆盖管理员专用查看、连接、编辑、解除关联、永久删除和审计记录。
- 覆盖多项目关联、并发新增关联、无个人空间用户及已删除用户等边界。
- 端到端验证项目切换器无其他个人空间，且只能从用户管理进入。
